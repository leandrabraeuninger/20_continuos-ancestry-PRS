Admixture simplex (3-population projection)

Each point is one individual's true ancestry vector, projected onto the African / European / East Asian corners of the simplex (South Asian & American/Indigenous folded into point radius as residual admixture). Corner-hugging = low α₀; centroid-clustering = high α₀.

Self-report vs. genetic ancestry

Rows = true dominant genetic ancestry, columns = self-reported label (numbered, see legend above). Diagonal = concordant. Off-diagonal mass grows as concordance c falls; its shape depends on the mismatch mode.

Phenotype: genetic vs. ancestry-confound contribution

—
Each point: one individual's true polygenic (causal-SNP) score vs. simulated phenotype, colored by dominant ancestry. A naive regression ignoring ancestry will be biased by the confound cloud's vertical offset between colors.

Causal effect size by population (effect attenuation knob)

—
Effective per-SNP effect size used for each population's individuals. At attenuation = 1.0 every population shares the same effect (no causal shift). Lowering it keeps the European (pop 2) effect fixed and shrinks the rest — the generative analogue of trans-ancestry PRS portability decay.
